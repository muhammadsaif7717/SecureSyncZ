# SecureSyncZ Future Tasks & Features Roadmap

**Browser Extension (Chrome / Firefox / Edge):** Develop a companion browser extension for seamless auto-filling of passwords and credit cards across websites.

**Biometric Authentication (WebAuthn):** Allow users to unlock their vault using FaceID, TouchID, or Windows Hello instead of typing their master password every time.

**Two-Factor Authentication (2FA / MFA):** Add an extra layer of security for logins using Authenticator apps (TOTP) or Hardware Keys (e.g., YubiKey).

**Secure Vault Sharing:** Implement public/private key cryptography to allow users to securely share specific passwords or notes with other registered users without compromising the zero-knowledge architecture.

**Secure File Attachments:** Allow users to upload and encrypt small files or images (like passport photos or ID scans) directly inside their Secure Notes.

**Real-time Cross-Device Sync:** Implement WebSockets to instantly sync changes (like adding a new password) across all active sessions on different devices.

**Custom Vault Categories:** Let users create custom folders and categories (beyond just tags) to better organize their growing list of credentials.
